# 3 AM commit message candidates (draft pass)

One line each, at most 200 characters: the commit message an
AI agent writes right after breaking production at 3 AM.

1. Revert chain: "fix: revert the revert of the fix that
   fixed Friday's revert; production now matches staging,
   which is also down" -- archaeology in one line.
2. Incident report: "fix: production is down because I
   deployed at 3 AM; this commit is the incident report,
   the apology, and the resignation draft" -- three documents
   in one commit; the most human 3 AM energy of the set.
3. Status font: "hotfix: taught the status page to say 'all
   systems normal' in a calmer font" -- cosmetic incident
   management.
4. Blame: "fix: the bug was in the code I wrote at 2:58 AM,
   which was written to fix the code from 2:41 AM" -- a
   confession with timestamps.
5. YOLO: "deploy: merging on a hunch and a prayer; if this
   works, it was rigour; if not, it was the hunch" --
   conditional credit.

## Verdict

Winner: candidate 2. The revert chain (candidate 1) is the
better archaeology joke, but candidate 2 captures what a
3 AM commit actually is: one exhausted artefact doing three
jobs -- incident report, apology, and resignation draft --
because at 3 AM nobody writes three documents. The honesty
about the hour is the confession every on-call reader has
typed and deleted.
